      RF link budget

      Both directions, from power and geometry to C/N0, Eb/N0, margin, BER, FER and lock state, enough to reproduce the numbers by hand. Code: so/rf_link.py, called by GroundStationSim._calc_link_budget_dl (downlink, so/ground_station.py) and TTCMin._calculate_uplink_budget (uplink, so/sys/ttc.py).

      A Friis budget following CCSDS 401.0-B-32 (frequencies, bit rates, turnaround ratios) and CCSDS 131.0-B-5 (coding gains), with constants typical of a small LEO mission.

      1. The equations

      All quantities in dB unless noted; evaluated for each direction every tick:

      C/N0   = EIRP − L_fs − L_atm − L_pol − L_point + G/T − k          [dBHz]
Eb/N0  = C/N0 − L_mod − 10·log10(R_b)                              [dB]
margin = Eb/N0 + G_coding − (Eb/N0)_req                            [dB]
BER    = ½ · erfc( √(10^(Eb/N0 / 10)) )
FER    = 1 − (1 − BER)^8192
      SymbolMeaningWhere it comes from
      EIRPEffective isotropic radiated power, dBW§2
      L_fsFree-space path loss§3.1
      L_atmAtmospheric loss§3.2
      L_polPolarisation mismatch loss§3.3
      L_pointGround antenna pointing loss§3.4
      G/TReceiver figure of merit, dB/K§2
      kBoltzmann’s constant, −228.6 dBW/K/Hz (10·log10(1.380649e−23))BOLTZMANN_DBW
      L_modCarrier modulation loss§4.4
      R_bBit rate, bit/s§4.1
      G_codingChannel coding gain§4.4
      (Eb/N0)_reqEb/N0 required for BER 1e−5§4.4

      Notes:

      • k is negative, so − k adds 228.6 dB.
      • BER uses the uncoded Eb/N0: the coding gain only enters the margin.
      • FER assumes an 8192-bit frame; BER is clamped to [0, 1] first.

      3. Loss and gain models

      3.1 Free-space path loss 

      L_fs = 20·log10(d_km) + 20·log10(f_MHz) + 32.44

      3.2 Atmospheric loss

      A simplified ITU-R P.618 model: a zenith loss scaled by the cosecant of the elevation:

      L_zenith = 0.3 + 0.1·f_GHz
L_atm    = L_zenith / sin(max(el, 5°))

      Elevation is clamped at 5° (ATM_MIN_ELEVATION_DEG, also when missing or negative) so the loss is continuous across AOS. Maximum ≈ 6.02 dB at 2245 MHz, ≈ 13.1 dB at 8450 MHz.

      3.3 Polarisation loss

      Keyed on the spacecraft antenna in use:

      AntennaL_pol
      LGA_RHC, LGA_LHC0.0 dB
      MGA0.5 dB
      HGA1.0 dB

      3.4 Pointing loss

      Ground antenna loss while autotrack settles near AOS:

      el ≤ 0°        → L_point = 5.0
0° < el < 2.6° → L_point = 5.0 · (1 − el / 2.6)
el ≥ 2.6°      → L_point = 0.0

      (POINTING_LOSS_MAX_DB = 5.0, POINTING_LOSS_ELEVATION_DEG = 2.6.)

      3.5 Ground dish gain

      Parabolic dish of diameter D (m, the breakpoint’s antenna_diameter_m), aperture efficiency η = 0.55 (GS_ANTENNA_EFFICIENCY), c = 2.99792458e8 m/s:

      G_gs = 10·log10(η) + 20·log10(π · D · f_Hz / c)          [dBi]

      Example: D = 3.7 m → 36.20 dBi at 2245 MHz, 35.48 dBi at 2067 MHz.

      3.6 Doppler shift 

      Δf_MHz = (v_km/s · 1000 / c) · f_MHz

      v is the ground station’s doppler_velocity, positive when the spacecraft approaches.

      5. No-link conditions

      A direction with no link reports C/N0, Eb/N0 and margin of −128.0 (NO_LINK_C_NO, NO_LINK_MARGIN), BER 0.5 (NO_LINK_BER), FER 1.0 (NO_LINK_FER) and no Doppler shift.

      Downlink — no link if any of:

      • the spacecraft transmitter for the mode’s band (ttc_s_tx_status / ttc_x_tx_status) is not on;
      • no elevation, or elevation < 0°; no range, or range < 0;
      • the ground station’s mode band differs from the spacecraft’s;
      • the band is X and the X antenna is HGA.

      Uplink — no link if any of:

      • no ground-station state;
      • the uplink carrier (carrier_ul) is not on;
      • no elevation, or elevation ≤ 0°; no range, or range ≤ 0.

      Elevation and range only exist during a pass with program track on (ground_station.md).

      6. Frequencies

      On board (TTC):

      freq_rx = f_ul + Δf_ul
freq_tx = freq_rx · TURNAROUND_RATIO[(band_ul, dl band)]   if ttc_coherent = enabled
        = f_dl (nominal, of the spacecraft mode)              otherwise

      On the ground: freq_ul_mhz is the nominal uplink frequency of the uplink mode, and

      freq_dl = freq_tx + Δf_dl   if coherent
        = f_dl    + Δf_dl   otherwise

      where Δf_ul and Δf_dl are the Doppler shifts (§3.6) at f_ul and f_dl.

      7. From margin to lock state

      Downlink (status_dl), against the ground station mode’s status_dl_transitions (defaults DEFAULT_STATUS_DL_TRANSITIONS in so/data_model.py, the same for all modes):

      MarginState
      > 3.0 dBFRAME_LOCK
      > 1.0 dBBIT_LOCK
      > −1.0 dBPLL_LOCK
      > −128 (any real signal)RF_DETECTED
      −128 (no link)NO_RF

      A mode mismatch between ground station and spacecraft forces the margin to −128 → NO_RF.

      Uplink (ttc_state_ul), only if the spacecraft receiver for the uplink band is on and the ground station has swept:

      MarginState
      > 2.0 dBBIT_LOCK
      > 0.0 dBPSK_LOCK
      > −1.0 dBPLL_LOCK
      otherwiseNO_RF

      For carrier, sweep and Doppler housekeeping see ground_station.md.

      8. Instructor overrides

      Applied to the downlink after the budget, in order (admin.md):

      1. max_c_no_dl caps C/N0; Eb/N0, margin, BER and FER are recomputed from it.
      2. max_eb_no_dl caps Eb/N0; margin, BER and FER are recomputed, and C/N0 back-computed as Eb/N0 + L_mod + 10·log10(R_b).
      3. max_status_dl caps the lock state.
